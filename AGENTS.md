# Agent Instructions for This Repository

## Product planning memory

- Always keep future ideas in `docs/ROADMAP.md`.
- When a feature or enhancement is discussed but not implemented in the same session, add it to `docs/ROADMAP.md` under `Backlog`.
- If we decide a backlog idea is the next priority, move it to `Planned Next`.
- Keep roadmap items concise and action-oriented.

## Planning workflow

- For roadmap updates, prefer editing `docs/ROADMAP.md` over creating scattered todo files.
- Preserve existing wording where possible; append new items rather than rewriting history.
