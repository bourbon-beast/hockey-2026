## 2025-02-18 - Added Accessibility Attributes to Remove Player Buttons
**Learning:** Icon-only buttons used to perform critical actions (such as removing a player from a team) require explicit ARIA attributes (like `aria-label`) and visual hints (like `title`) to ensure they are accessible via screen readers and understandable by mouse users. Inner purely-visual icons should be explicitly hidden from screen readers using `aria-hidden="true"`. Furthermore, they should show a visible outline when keyboard-focused (`focus-visible:ring-2`, etc.) to provide essential navigational feedback.
**Action:** Consistently apply `aria-label`, `title`, and explicit keyboard focus classes (`focus-visible`) to all icon-only interactive elements in lists, and use `aria-hidden="true"` on the SVG components.
